RetroPlay third-party software notices
====================================

RetroPlay serves the following third-party software from its own site, unmodified except where
noted. The full license text of each emulator core is included inside its .data archive
(license.txt). RetroPlay is a personal, non-commercial project.

1. EmulatorJS 4.2.3 — GNU General Public License v3.0
   Project: https://github.com/EmulatorJS/EmulatorJS
   Files: /emulatorjs/4.2.3/data/ (loader, runtime, compression helpers, localization).
   The runtime bundle emulator.min.<hash>.js is built by RetroPlay from the unmodified 4.2.3 sources
   with a small appended addition (retroarch.cfg extras, files written next to the game, a picture
   size limit with software WebGL, and RetroPlay's own MAME 2003-Plus and Snes9x 2005 Plus builds
   registered as MAME and SNES cores).
   Source of the addition: scripts/emulatorjs-runtime.mjs in the RetroPlay repository.

2. RetroArch (built into every EmulatorJS core) — GNU General Public License v3.0
   Project: https://github.com/libretro/RetroArch

3. Emulator cores
   The cores below are built by RetroPlay (.github/workflows/cores-fast.yml in the RetroPlay
   repository) from the same sources and with the same toolchain as the EmulatorJS 4.2.3 packages
   (emsdk 3.1.74, EmulatorJS/RetroArch commit 6dd4353937ef48b6ec0bfbdbb15d1c5992d86927), linked
   without Asyncify and with RetroArch's Web Audio driver; files /emulatorjs/4.2.3/data/cores/cores-fast-r*/.
   The EmulatorJS 4.2.3 builds are also served at /emulatorjs/4.2.3/data/cores/ (Genesis Plus GX is
   served only as that build).
   - Nestopia UE (NES) — GNU General Public License v2.0 — https://github.com/EmulatorJS/nestopia (6b08ec91)
   - FCEUmm (NES) — GNU General Public License v2.0 — https://github.com/EmulatorJS/libretro-fceumm (d9d7e141)
   - Snes9x (SNES) — Snes9x non-commercial license — https://github.com/EmulatorJS/snes9x (6ca2343e)
   - Snes9x 2005 Plus (SNES) — Snes9x non-commercial license with GPL v2 and MIT parts (see its
     license.txt) — https://github.com/libretro/snes9x2005 (a79dfe90), built with blargg's audio
   - PicoDrive (Mega Drive) — MAME-style non-commercial license — https://github.com/EmulatorJS/picodrive
     (09d3cb63), with two changes for WebAssembly that fall under the same license: EmulatorJS's own
     Emscripten fix (their commit 51f7667) and a corrected memory handler signature; both are the
     files in cores/picodrive/ of the RetroPlay repository
   - Genesis Plus GX (Mega Drive) — Genesis Plus GX non-commercial license — https://github.com/EmulatorJS/Genesis-Plus-GX
   - FinalBurn Neo (arcade) — FinalBurn Neo non-commercial license — https://github.com/EmulatorJS/FBNeo (dedd04f2)
   - MAME 2003-Plus (arcade) — MAME non-commercial license — https://github.com/EmulatorJS/mame2003-plus-libretro (3a72dae3)
   - FB Alpha 2012 CPS2 (arcade) — FB Alpha non-commercial license — https://github.com/EmulatorJS/fbalpha2012_cps2 (3fb5b89d)
   - MAME 2003-Plus, current sources (arcade, Namco System 12) — MAME non-commercial license (see the
     license.txt in its .data archive) — built by RetroPlay, not part of the EmulatorJS packages:
     source https://github.com/libretro/mame2003-plus-libretro at commit 64b3c38ac6dae0fb513e6b881fb3bfc31fca54c4,
     modified by RetroPlay for speed (a PSX CPU to WebAssembly recompiler, WebAssembly SIMD drawing,
     interlaced field drawing; the changes are the files in cores/mame2003_plus_next/ of the RetroPlay
     repository and fall under the same license), compiled with EmulatorJS/RetroArch (commit
     6dd4353937ef48b6ec0bfbdbb15d1c5992d86927, its pixel conversions compiled with SIMD) and
     emsdk 3.1.74 by .github/workflows/cores.yml in the RetroPlay repository; files
     /emulatorjs/4.2.3/data/cores/mame2003_plus_next-*.

4. Arcade game lists (ROM set names, sizes and CRC32 values only)
   - FinalBurn Neo v1.0.0.03 arcade DAT (EmulatorJS/FBNeo, commit dedd04f2)
   - MAME 2003-Plus metadata/mame2003-plus.xml (EmulatorJS/mame2003-plus-libretro, commit 3a72dae)
   - FB Alpha 2012 CPS2 ROM tables from src/burn/drv/capcom/d_cps2.c (EmulatorJS/fbalpha2012_cps2, commit 3fb5b89)
   - Namco System 12 ROM tables from src/drivers/namcos12.c (libretro/mame2003-plus-libretro, commit 64b3c38a)
   These lists contain no game data. No ROM, BIOS or game file is distributed with RetroPlay.

   Cover lists (public/assets/covers/*.json: picture names and ROM CRC32 values only)
   - Picture names from libretro-thumbnails (https://github.com/libretro-thumbnails), repositories
     Nintendo_-_Nintendo_Entertainment_System (4d21463b), Nintendo_-_Super_Nintendo_Entertainment_System
     (cdd8f1d4), Sega_-_Mega_Drive_-_Genesis (b81fd421), FBNeo_-_Arcade_Games (9d04d3f2), MAME (98a41676)
   - No-Intro ROM checksums from libretro-database metadat/no-intro (commit 77f15a81)
   The pictures themselves are not distributed with RetroPlay: the app fetches a game's picture from
   raw.githubusercontent.com when the player has that game, as RetroArch does.
